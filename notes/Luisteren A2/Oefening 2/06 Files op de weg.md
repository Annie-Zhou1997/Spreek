# Files op de weg：广播里的路况

> 听力 A2 · 练习 2 · 第 6 篇 · 广播：路况播报

## 原文

Mario luistert naar de radio. Hij hoort een bericht over files.
En dan nu de files.
Op de snelweg A2 tussen Amsterdam en Utrecht staat vijf kilometer file. De oorzaak is een ongeluk met drie auto's.
Bij Rotterdam op de snelweg A4 naar Delft staat een kapotte vrachtwagen. Daarom staat er nu een file van vier kilometer.
Over een half uur zal het verkeer weer kunnen doorrijden.
De laatste file staat op de A50 bij Apeldoorn. Daar is een vrachtwagen met eieren omgevallen.
De vrachtwagen en de eieren liggen op de weg. De weg wordt nu schoongemaakt. Er staat een file van tien kilometer.
Ten slotte nog een bericht voor mensen die met de trein reizen: tussen de stations Arnhem en Utrecht rijden geen treinen. U kunt met de NS-bussen reizen.
Tot zover de files.

## 译文

Mario 在听广播，听到路况播报。「现在是路况。A2 高速阿姆斯特丹到乌得勒支之间堵车五公里，原因是一起三辆车的事故。鹿特丹附近 A4 高速往代尔夫特方向有一辆坏掉的卡车，所以现在堵四公里。半小时后车流可以重新通行。最后一处堵车在阿珀尔多伦附近的 A50，一辆运鸡蛋的卡车翻了，卡车和鸡蛋都在路上，正在清理路面，堵了十公里。最后给坐火车的人一条消息：阿纳姆和乌得勒支之间没有火车，可以乘坐 NS 大巴。路况到此为止。」

## 考题

Hoe lang is de file op de snelweg A2 tussen Amsterdam en Utrecht?
- Vier kilometer.
- Vijf kilometer.
- Zes kilometer.

Waarom staat er een file op de snelweg A4 bij Rotterdam?
- Er wordt aan de weg gewerkt.
- Er is een ongeluk gebeurd met drie auto's.
- Er staat een kapotte vrachtwagen.

Mario wil met de trein van Arnhem naar Utrecht. Wat kan hij het beste doen?
- Via Apeldoorn reizen.
- Met een taxi reizen.
- Met de NS-bus reizen.

答案：Vijf kilometer；Er staat een kapotte vrachtwagen（三辆车的事故是 A2 的）；Met de NS-bus reizen。这篇考的是「哪条路配哪个原因」，听的时候要把路名和原因配对记住。

## 语法点

### Er staat ... file：er 开头的存在句

- Op de A2 staat vijf kilometer file.
- Er staat een file van tien kilometer.
- Er staat een kapotte vrachtwagen.

### 被动：wordt + 过去分词

- De weg wordt nu schoongemaakt.
- Er wordt aan de weg gewerkt.（选项里的，意思是「在修路」）

### zal / zullen：预计将来

- Over een half uur zal het verkeer weer kunnen doorrijden.
- Morgen zal het regenen.

### 关系从句 die：mensen die ...

- een bericht voor mensen die met de trein reizen
- de mensen die in de file staan

### 路况播报的固定说法

- En dan nu de files.（开头）
- Tot zover de files.（结尾）
- staat ... kilometer file / een file van ... kilometer
